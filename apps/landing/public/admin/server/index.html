      สำรองข้อมูล

        วิธีกู้ข้อมูลจากไฟล์สำรอง

        บนเครื่องเซิร์ฟเวอร์ ในโฟลเดอร์ที่ deploy ไว้ (แทน FILE ด้วยชื่อไฟล์ด้านบน) หยุดแอปก่อนกู้:

        docker compose stop landing studio
docker compose exec backup pg_restore -d naka --clean --if-exists /backups/FILE
docker compose start landing studio

        ควรคัดลอกโฟลเดอร์สำรอง (volume pg-backups) ไปเก็บนอกเครื่องด้วย ไฟล์สำรองบนดิสก์เดียวกันจะหายไปพร้อมดิสก์
